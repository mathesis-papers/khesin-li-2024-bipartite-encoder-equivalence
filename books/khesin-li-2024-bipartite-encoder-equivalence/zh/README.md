# 看起来不同，为什么还是同一个编码图？

想象有两排插座：左边是输入，右边是输出，连线表示某个输入接到某个输出。只允许跨排连线时，可以把图抄成一张由 0 和 1 组成的表：每行是一个输入，每列是一个输出。左边两行、右边三列的一个例子是

$$
\begin{pmatrix}1&0&1\\0&1&1\end{pmatrix}.
$$

前两列各接一个输入，第三列同时接两个。把第二行加到第一行时，按模 2 计算：$1+1=0$，即两条记录相消。这次修改把共享输出移到了第二列，却没能把它消掉。能否用更灵活的图变换做到这一点？

- [在变换中保留的信息](moves.md)：即使中途出现同排连线，仍有一种可比较的量。
- [两行、三种非零列](two-inputs.md)：数一数四种列，就能找出同类二部图中最少的共享输出。
